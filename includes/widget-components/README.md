# PHP widget components
Deploy a trusted PHP file here (not via a public upload). Return an array with a render callable accepting PDO and optionally a validate callable accepting PDO and submitted fields. The latter returns validated field-name/value pairs or throws InvalidArgumentException. Use names fields[variable] for Contact Form controls. In Widget Manager HTML enter {{component:filename.php}}; save and attach the existing widget shortcode to a Custom HTML field. Existing bare markers are resolved by filename as well. No core changes are needed for additional components. Only Contact Form has the generic validation integration in this release; other form handlers retain their existing submission paths. Membership selector records interest only, not an actual subscription change. Components are trusted application code; do not place untrusted PHP here.
